# Máquina de Guion

Máquina de escribir para guiones de cómic, con planificador de pliegos.

Es una aplicación web instalable: se abre con Google Chrome y se instala con el botón «Instalar» de la barra de direcciones. Funciona sin conexión.

Los guiones se guardan en una carpeta del propio ordenador, la que elige cada usuario. Ningún guion ni ninguna nota se sube a este repositorio ni a ningún servidor.

Este repositorio contiene solo el programa, generado automáticamente: no se edita a mano.
